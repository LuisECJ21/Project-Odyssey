# Notas flujo de internet:
## Pregunta 1 (primer concepto)
- El primer elemento en el flujo de internet, es el cliente, puntualmente el navegador.
- El siguiente paso no es determinar si hay internet o no, que ademas, depende de muchos factores poder afirmar si hay o no hay internet. Para poder enviar el byte 1, no se hace a www.google.com, porque las maquinas no entienden nombres, como lo hemos visto en otros cursos y configuraciones, la comunicación entre dos dispositivos se hace mediante sus identificadores, es decir las IPs pero como dijimos, las máquinas no entienden nombres, entienden IPs, y de ahi nace justo la razón de ser del DNS,  Entonces el navegador dice, quiero comunicarme con www.google.com pero para enviar un paquete necesito algo como 168.127.xx.xx

## Pregunta2 (DNS)
- El navegador obtiene la IP de www.google.com a través del servicio DNS, que esta formado por DNS, que es el protocolo y define las reglas para el intercambio de informaciones y el servidor DNS, quien recibe la consulta y responde, por ejemplo, el DNS de Google es 8.8.8.8
- En resumen, DNS es un sistema distribuido que responde a la pregunta, ¿cuál es la dirección IP asociada a este nombre de dominio?

Se debe tener cuidado con el uso de las palabras y los conceptos que ellas traen,

## Pregunta3 (TCP)
- Ya tengo el navegador, ya se donde está google, ¿cómo le hago para empezar a a hablar con esa computadora?
- Aquí es donde entra TCP, pero merece la pena mencionar que DNS, solo nos dice la IP de donde está, en este caso Google, se necesita establecer una comunicación entre dos máquinas que posiblemente nunca antes habían hablado, porque DNS te hace llegar a la puerta, pero TCP, toca la puerta, espera a aue abran, decir quien eres y si te dejen pasar, esto hace TCP, iniciar una conversación confiable.
- Imaginemos que hablan dos personas por teléfono:
    - Que se necesita para empezar una conversación?
    - Basta con que tenga el numero telefónico?
    - Hace falta algo mas?
        - Ya se tiene la dirección IP, que tomamos del DNS
        - Se necesitan puertos, que más adelante se verán, porque como sabemos, se estan ejecutando múltiples servicios y procesos, como saber cual debe responder?
        - Debe existir un camino de comunicación
        - Debe responder a quien llamamos, porque no se puede asumir que esta disponible, se debe preguntar y recibir una respuesta.
